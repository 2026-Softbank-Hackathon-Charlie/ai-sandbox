# 0001. 복제 경로 조정 권한은 플랫폼 초안에서 보존한다

- 상태: 채택
- 날짜: 2026-11-07

## 상황

세 환경 DB 그룹의 플랫폼 초안에는 `allowSourceRewire`가 들어간다. 오래된 플랫폼·엔진 타입과 엄격한 모델 출력 스키마를 거치면 필드가 유실되어 같은 계획이 기본 strict topology로 실행될 수 있다. 반대로 모델이 권한을 임의 활성화하도록 허용해서도 안 된다.

## 결정

플랫폼·엔진 의존성을 해당 계약을 제공하는 커밋으로 갱신한다. 출력 스키마에 boolean을 추가하고, 모델 응답이 플랫폼 초안의 값과 일치해야 유효하다고 판단한다. 검증 통과 뒤에도 권한은 원래 초안에서 다시 복원한다. diagnosis patch로 이 필드를 수정할 수 없다. typed draft·제출 본문·계획 digest·SandboxPlan에서도 값을 보존한다. target replica 재연결 권한을 추가하거나 source-only 권한의 의미를 넓히지 않는다.

SandboxPlan은 엔진 Parse를 거치지 않고 구조체를 전달하므로 생략된 `maxFenceGate`만 엔진 기본값 20초로 맞춘다. 운영자가 명시한 값은 그대로 유지하고 기본값 일치와 명시값 보존을 테스트한다.

## 검토한 대안

- 알 수 없는 필드를 무시하는 기존 타입 유지: 권한과 리허설 digest가 유실된다.
- 모든 모델 계획에 권한 활성화: 등록 앱 범위를 벗어난 권한 확대가 된다.
- 모델 값만 신뢰: 검증 또는 복원 중 한 경로가 누락되면 변조가 통과할 수 있다.

## 결과

기존 false/생략 계획의 직렬화는 유지한다. 실제 권한 결정과 실행 직전 등록 앱 범위 검증은 플랫폼이 계속 담당한다. 단위 테스트는 실제 LLM 응답·Kubernetes Job·세 클라우드 간 네트워크·MinIO 사진 이전이나 운영 DB 이전 성공을 증명하지 않는다. 로컬 디스크 부족으로 완료하지 못한 검증은 CI에서 수행한다.
